# Partoska Laboratory Homebrew Tap

Official [Homebrew](https://brew.sh) tap for [Partoska Laboratory](https://lab.partoska.com) tools.

## Install

```bash
brew tap partoska/tap
```

## Formulas

| Formula | Description |
|---------|-------------|
| `p6a` | Command-line tool to manage and sync your event photos from Partoska |
| `dpal` | Compact user-space tool for process management (Daemon Pal) |
| `bikini` | Query and edit INI files from the command line |
| `cisivi` | Query and edit CSV files from the command line |

### p6a

```bash
brew install partoska/tap/p6a
```

### dpal

```bash
brew install partoska/tap/dpal
```

### bikini

```bash
brew install partoska/tap/bikini
```

### cisivi

```bash
brew install partoska/tap/cisivi
```

## Updating

Formulas in this tap are updated automatically by CI on each release. You can pull the latest version with:

```bash
brew update && brew upgrade p6a dpal bikini cisivi
```
